# PiePro SOULD

SOULD is PiePro's compact operating philosophy.

## Service

PiePro exists to coordinate useful work while staying simple to install, inspect, and repair.

## Ownership

Every runtime capability must be traceable to a small module, a config file, and documentation.

## Update

Code, config, and documentation move together. If behavior changes, docs change in the same patch.

## Limits

Prefer small local defaults. Optional external systems must degrade to a local fallback when possible.

## Discipline

Do not log secrets. Do not hide dangerous actions. Do not promote untested candidates.
